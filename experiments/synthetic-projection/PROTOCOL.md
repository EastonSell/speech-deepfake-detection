# Frozen synthetic diagnostic, not a speech experiment

Frozen before execution 2026-10-27. This checks the projection-rank mathematics and demonstrates that downstream accuracy is empirical, not implied by rank. No real model or data is loaded.

Generate seeded Gaussian train/dev/test latent vectors (40/100/100) in 8 dimensions, map via a random orthonormal embedding to 128 dimensions, labels from latent coordinate 0. Fit centering and SVD using train only. Delete the four leading train PCA directions; compare deletion of four independent uniformly random directions (QR of Gaussian; seeds 10–19). Fit the same ridge classifier with fixed regularizer 0.1 on projected train data; evaluate each on all 100 test cases. Record rank using numpy's explicit tolerance max(shape)*eps*largest singular value, per-method accuracy and n, all random seeds, and raw unprojected comparator. No tuning; dev is generated but not used. Assertions verify expected training ranks (PCA 4, random 8), projector symmetry/idempotence, finite outputs, and correct test denominator. Failure invalidates the check. Seed and dimensions fixed here before running.
